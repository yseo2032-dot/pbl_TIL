2. 핵심 정리
   1) CSS BOX를 정확히 이해하는 것!!
   inline- 한줄 표시
    <a> <img> <span> 태그로 감싸진 내용만큼만 영역을 차지
   => 중요!! 넓이와 높이는 조절 불가!!

   block- 개별 요소마다 줄을 바꿈
   <h1> <p> <div> 
   => 인라인과 달리 넓이와 높이로 요소의 크기를 조절함
     
   2) CSS 특성
      폭포수- 같은 태그에 대한 규칙이 있는 경우 마지막에 작성된 태그가 적용이 됨
      => 그래서 내가 분명 이 태그를 작성했는데 적용이 안되었을 때 동일한 태그가 있는지 꼭 확인해볼 것
      상속- 부모요소의 CSS 규칙을 자식요소가 상속하여 적용
      => 그치만 자식요소가 가지고 있으면 우선하여 적용함
